# Ludo

## ▶ [Play the game](https://libyan11.github.io/ludo/)

https://libyan11.github.io/ludo/

Ludo in your browser, on phone or computer. Play online with friends, or against the computer. Part of [Game Night](https://libyan11.github.io/).

**Play with friends:** one person taps *Create a room* and shares the 4-letter code or link. Everyone else types the code and taps *Join room*. 2 to 4 players, and the host can fill empty seats with computer players. If someone drops out, the computer plays for them until they come back.

**Rules**
- Roll a 6 to bring a token out onto your start square.
- Move one token forward by the number rolled, round the board and up your own coloured lane.
- Roll again after a 6, a capture, or getting a token home. Three 6s in a row loses the turn.
- Land on another player's token to send it back to their corner. Stars and coloured start squares are safe.
- You need the exact number to reach home.
- The host picks whether the game ends when the first player gets all 4 home, or keeps going until one player is left.
